# Getting Help

Before asking, these usually have the answer:

- the [README](README.md): setup, configuration, endpoints, sign in flow and security notes
- the interactive API reference at `/docs` when the server runs locally
- [CONTRIBUTING.md](CONTRIBUTING.md) for the architecture and development workflow
- [CHANGELOG.md](CHANGELOG.md) when upgrading

Still stuck?

- **Found a bug?** Open a [bug report](https://github.com/KhaledSaeed18/node-authentication-template/issues/new?template=bug_report.yml) with the steps to reproduce.
- **Have an idea?** Open a [feature request](https://github.com/KhaledSaeed18/node-authentication-template/issues/new?template=feature_request.yml).
- **Something unclear in the docs?** Open a [documentation issue](https://github.com/KhaledSaeed18/node-authentication-template/issues/new?template=documentation.yml).
- **Security issue?** Never in a public issue. Follow the [Security Policy](SECURITY.md).

This project is maintained in spare time, so please be patient and give as much detail as you can.
